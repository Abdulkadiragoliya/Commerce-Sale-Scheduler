# Changelog

All notable changes to **Commerce Sale Scheduler** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## 1.0.1 - 2026-10-14

### Changed
- Updated `LICENSE.md` to match the official Craft License required for Craft Plugin Store distribution.

## 1.0.0 - 2026-10-13

### Added
- Initial release for Craft CMS 5 & Craft Commerce 5.
- Dynamic scheduled sales and promotional discounting engine.
- Percentage and fixed discount calculations with price floor protection.
- Product, variant, category, and exclusion targeting rules.
- Real-time sale conflict detection and deterministic priority resolution.
- Responsive live countdown timer widgets (`boxed`, `compact`, `minimal`).
- Promotional badges with image assets and custom positioning.
- Strikethrough pricing and consolidated savings pills (`Save $X (Y%)`).
- Storefront CSS & JS auto-injection and manual asset control.
- Control Panel dashboard, sale management UI, and global settings.
- Comprehensive Twig API (`saleScheduler*` and `craft.saleScheduler.*`).
- Full Cart & Checkout integration with Craft Commerce line items and adjusters.
